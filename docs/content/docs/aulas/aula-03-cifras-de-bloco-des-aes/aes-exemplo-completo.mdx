## Estado inicial e rodada 0

O estado inicial é o texto claro; `AddRoundKey` com `K0` (a própria chave) dá o início da rodada 1. Conferência do primeiro byte: `32 XOR 2b = 19`.

```
Texto claro      K0 (a chave)     Início da rodada 1
32 88 31 e0      2b 28 ab 09      19 a0 9a e9
43 5a 31 37      7e ae f7 cf      3d f4 c6 f8
f6 30 98 07  ⊕   15 d2 15 4f  =   e3 e2 8d 48
a8 8d a2 34      16 a6 88 3c      be 2b 2a 08
```

## Rodada 1, camada por camada

<Tabs items={['SubBytes', 'ShiftRows', 'MixColumns', 'AddRoundKey']}>
  <Tab value="SubBytes">
    Cada byte pela S-box de forma independente. Por exemplo, `19` vira `d4`.

    ```
    d4 e0 b8 1e
    27 bf b4 41
    11 98 5d 52
    ae f1 e5 30
    ```
  </Tab>
  <Tab value="ShiftRows">
    Linhas deslocadas em 0, 1, 2 e 3 posições.

    ```
    d4 e0 b8 1e
    bf b4 41 27
    5d 52 11 98
    30 ae f1 e5
    ```
  </Tab>
  <Tab value="MixColumns">
    A coluna `(d4 bf 5d 30)` vira `(04 66 81 e5)`: os quatro bytes de saída dependem dos quatro de entrada.

    ```
    04 e0 48 28
    66 cb f8 06
    81 19 d3 26
    e5 9a 7a 4c
    ```
  </Tab>
  <Tab value="AddRoundKey">
    XOR com `K1` = `a0fafe17 88542cb1 23a33939 2a6c7605` (em colunas). Primeiro byte: `04 XOR a0 = a4`.

    ```
    a4 68 6b 02
    9c 9f 5b 6a
    7f 35 ea 50
    f2 2b 43 49
    ```
  </Tab>
</Tabs>

## Reprodução com OpenSSL

O resultado pode ser reproduzido com o OpenSSL (modo ECB, sem padding, apenas para verificar um bloco isolado):

```bash
echo -n 3243f6a8885a308d313198a2e0370734 | xxd -r -p \
  | openssl enc -aes-128-ecb -K 2b7e151628aed2a6abf7158809cf4f3c -nopad | xxd -p
```

A saída esperada é `3925841d02dc09fbdc118597196a0b32`. O uso de ECB aqui serve só para cifrar **um único bloco** e comparar com o vetor de teste; para mensagens reais, o ECB é inadequado (ver [ECB](/docs/aulas/aula-04-modos-de-operacao-e-aead/ecb)).

<Callout title="Aplicação no artigo" type="info">
  Os **vetores de teste** oficiais são a base de qualquer verificação de implementação. O experimento da pesquisa segue o mesmo princípio: resultados reproduzíveis por um comando e conferíveis contra uma referência pública.
</Callout>
