## Como se conectam

O percurso das quatro primeiras aulas vai do **vocabulário** (o que é uma cifra, contra quem ela se defende) à **peça usada na prática** (AES em modo autenticado, como no TLS 1.3), passando por um caso histórico de migração (DES) e pelo panorama pós-quântico.

```
Aula 1  panorama e migração PQ  ───────────────────────────────┐
Aula 2  paradigma → segurança perfeita → computacional → DES   │  tema da pesquisa:
Aula 3  princípios de projeto → DES revisitado → AES           ├─ troca de chaves no TLS 1.3
Aula 4  modos de operação → AEAD (GCM, ChaCha20-Poly1305)  ────┘
```
